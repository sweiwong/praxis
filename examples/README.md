# Example Protocols

This folder contains sample rehabilitation protocols generated by PRAXIS to demonstrate output quality.

Each protocol includes:
- Evidence-based research analysis with quality grading (1A, 1B, 2A, etc.)
- Phase-based rehabilitation progression
- Specific exercise prescriptions with dosage parameters (sets, reps, load, frequency)
- Return-to-sport/activity criteria
- Contraindications and precautions
- Outcome measures for tracking progress

## Available Examples

### 1. ACL Reconstruction Rehabilitation
**File:** `acl_reconstruction_protocol.md`

Comprehensive 4-phase protocol spanning 9-12 months post-surgery, including:
